## 2024-08-22 - Prevent URL Obfuscation via Unicode Non-characters
**Vulnerability:** The URL safety validation `isSafeUrl` and `isSafeWebUrl` used a `CONTROL_CHARS_REGEX` that missed invisible operators (e.g. Word Joiner \u2060) and Unicode noncharacters (\uFFFE-\uFFFF). An attacker could exploit this by embedding these characters in a URL string, potentially bypassing the protocol whitelist and executing XSS attacks or obfuscating dangerous URLs.
**Learning:** Hardcoded regex for string sanitization often misses edge cases in Unicode whitespace and control characters.
**Prevention:** Include broader Unicode non-character and invisible formatting ranges in regex-based sanitizers. Use `RegExp` constructor with escaped backslashes to include these ranges while bypassing strict linter rules against control characters.
