## 2024-05-18 - Array Truncation and Pagination Limits
**Learning:** Slicing large arrays locally after fetching all pages creates unnecessary garbage collection overhead and wastes network IO. Modifying `autoPaginate` to truncate arrays in-place (`arr.length = limit`) reduces GC overhead. Also, using `autoPaginate`'s `limit` option prevents fetching unnecessary pages in the first place.
**Action:** Use in-place truncation (`arr.length = limit`) for large array truncation right before returning instead of `.slice()`. Always pass the limit directly to `autoPaginate` to avoid redundant API requests.
