## 2024-08-20 - Early termination of Pagination
**Learning:** When using `autoPaginate` with a `limit`, fetching all pages from the Notion API and slicing the final result array is extremely inefficient.
**Action:** Always pass the `limit` inside the options object (`{ limit: input.limit }`) into `autoPaginate`. This allows `autoPaginate` to terminate the pagination loop early, drastically reducing network I/O, API rate limit consumption, and memory overhead. Additionally, use in-place array truncation (`allResults.length = limit`) inside `autoPaginate` to avoid the GC penalty of allocating a new array via `.slice()`.
